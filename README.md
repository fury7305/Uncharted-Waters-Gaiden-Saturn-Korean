# 대항해시대 외전 세가 새턴판 한국어 패치

세가 새턴용 **대항해시대 외전 (大航海時代外伝)** 일본판을 대상으로 제작한 한국어 패치입니다.

## 패치 정보

- 대상 기종: SEGA SATURN
- 대상 게임: 대항해시대 외전 일본판
- 패치 버전: v1.1
- 한국어화: 게임 내 텍스트 및 주요 UI
- 실기 테스트: SEGA SATURN + SAROO

## 주의사항

이 저장소에서는 게임 원본 이미지(BIN/CUE/ISO)를 제공하지 않습니다.

패치를 사용하려면 정품 게임에서 직접 준비한 원본 이미지가 필요합니다.
